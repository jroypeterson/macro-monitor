📊 macro-monitor

Disciplined US macro feed for the #macro Slack channel. Posts release headlines + charts for 9 Tier A families (CPI, payrolls, PCE, claims, GDP, JOLTS, PPI, retail sales, ECI).

📈 Current state dashboard
Latest value per Tier A family with mini-chart and links to each release report. Refreshed after every release post.
📅 2026 annual macro calendar
Year-long Tier A release schedule, month-by-month grid. Refreshed quarterly.
🌍 Global macro dashboard
Latest CPI / GDP / unemployment / policy rates for the eurozone, UK, China & Japan. Refreshed weekly.
🏥 Healthcare dashboards
From the hc_macro_policy project: weekly HC operating dashboard, plus the CMS rule-cycle calendar and CMS rates history.
🔧 Source on GitHub
Code, workflows, and design plan.
Per-release HTML reports live under archive/<family>/<period>.html but are linked from the dashboard above. Static-site deploy from the repo's outputs/ directory via GitHub Actions.
